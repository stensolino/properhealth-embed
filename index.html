What to test

  • Interactive iframe (intervention/protocol/question/post): renders the "Sign in to join the discussion" affordance → click Sign in → a popup opens on dev.properhealth.io. If you're already logged into the dev web in this browser, the popup auto-completes (reuses the session cookie); otherwise it shows the email/password form. After the popup closes, click Upvote / write a comment — the request carries Authorization: Bearer and no cookie (open DevTools → Network to confirm the credential shape).
  • Read-only widget (intervention/protocol/question/post): the card renders → "View" / "View full discussion →" opens the public dev web detail page in a new tab.
  • Read-only podcast: the list renders the podcast's interventions → click a row → an in-page modal opens (no new tab) with a "Personalise" lead-capture button.
  • Regression: the host page itself is never redirected to /login on a 401 inside the iframe — the embed re-shows "Sign in" and the host stays put.

Setup — what to enable in AWS dev

  1. Add THIS page's origin to the embed allowlist.
    Sign in to the dev admin portal → https://dev.properhealth.io/admin/system/embed-allowed-origins
    Add the exact origin shown in the green box above, e.g. https://your-test.netlify.app (no trailing slash, no path).
    The API's /embed/* controller checks the request Origin against this list on every embed call and returns 403 Origin not allowed otherwise. When the allowlist has no rows at all, all origins are permitted — but dev already has rows, so you must add yours.
  2. Find a real public entity UUID in dev. Pick any public intervention / protocol / question / post (or a podcast id for the podcast list) from the dev DB (admin UI or a DB query) and paste its id above. The embed only renders for resources that exist and are embeddable (public, not private/followers-only).
  3. Serve over HTTPS (not file:// — the origin check needs a real origin, and popups / secure-context APIs need HTTPS). This page is already deployed on a different-domain HTTPS host (GitHub Pages), which is what makes the embed genuinely cross-origin — the whole point.
